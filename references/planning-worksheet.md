## STEP 3: CONTENT OUTLINE

**Target Slide Count:** _____ (recommend 7; range: 5-10)

**Narrative Structure** (choose ONE):

### Option A: Problem → Insight → Example → Action

- Slide 1: Hook + Problem framing
- Slide 2: Why this matters / counterintuitive insight
- Slide 3: Concrete example or case study
- Slides 4-6: Actionable steps (one per slide)
- Final: CTA

### Option B: Numbered Framework (e.g., "The 5-C Model")

- Slide 1: Hook + framework name
- Slides 2-6: Framework element (one per slide)
- Final: How to apply or save for reference

### Option C: Step-by-Step Process

- Slide 1: Hook + desired outcome
- Slides 2-7: Step 1, Step 2, Step 3... (one per slide)
- Final: Result achieved

### Option D: Personal Narrative

- Slide 1: Hook (surprising outcome or lesson)
- Slides 2-5: Story progression
- Slide 6: The insight / lesson
- Slide 7: How it applies to viewer
- Final: CTA

### Option E: Data-Driven

- Slide 1: Hook + key stat
- Slide 2: Context (why this data matters)
- Slides 3-5: Visualizations + insights (one per slide)
- Slide 6: "So what?" (implication for viewer)
- Final: Action

## STEP 6: CONTENT RULES CHECK

Before designing, answer these:

**Clarity**
- [ ] Can someone understand the core message from headlines alone?
- [ ] Does each slide have ONE clear idea?
- [ ] Is the progression logical (one slide prepares for the next)?

**Length**
- [ ] Slide count: 5-15? (target 7)
- [ ] Each slide readable in under 5 seconds?
- [ ] Body text 30 words or fewer per slide?
- [ ] Headlines scannable in 2 seconds?

**Hook Quality**
- [ ] First slide hook is specific, not generic?
- [ ] Promises value upfront (not hidden until end)?
- [ ] Includes swipe indicator?

**Save-ability** (critical for algorithm)
- [ ] Would someone bookmark this to reference later?
- [ ] Frameworks are named and reusable?
- [ ] Checklists are complete and actionable?
- [ ] Insights are generalizable?

---

## STEP 7: PRE-PUBLICATION CHECKLIST

**Content**
- [ ] Slide 1 hook is compelling and specific
- [ ] Narrative arc is clear throughout
- [ ] No slide has more than 30 words
- [ ] Each slide takes 5 seconds or fewer to read
- [ ] Final slide has clear CTA
- [ ] Slide count is 5-15 (ideally 7)

**Design**
- [ ] Same 2 fonts throughout
- [ ] Same 3 colors throughout
- [ ] High contrast (readable on phone)
- [ ] One focal point per slide
- [ ] Margins consistent
- [ ] Logo in same position

**Technical**
- [ ] Format: PDF Standard (exported)
- [ ] Dimensions: 1080 × 1350px (portrait) or chosen size
- [ ] Text sizes: 24px+ body, 36px+ headlines
- [ ] File tested on mobile device
- [ ] No animations or transitions

**Caption**
- [ ] Starts with hook
- [ ] Clear value proposition
- [ ] One specific CTA
- [ ] 3-4 lines max
